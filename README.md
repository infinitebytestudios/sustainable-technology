# Sustainable Technology — E-Fiesta 2026

A six-page educational website created for the E-Fiesta 2026 web designing competition.

## Pages

1. Home
2. What Is Sustainable Technology?
3. Clean Energy
4. Smart Cities
5. Benefits & Challenges
6. Future of Sustainable Technology

## Technologies Used

- HTML5
- CSS3

## Project Structure

- `index.html` — Home page
- `what-is.html` — Introduction to sustainable technology
- `clean-energy.html` — Renewable and clean energy
- `smart-cities.html` — Sustainable urban technology
- `benefits.html` — Benefits and challenges
- `future.html` — Future of sustainable technology
- `style.css` — Shared stylesheet
